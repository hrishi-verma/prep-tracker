# Prep Tracker

LeetCode patterns with spaced revision, System Design tracks and an AI Fluency path, in one page.

- The page is `index.html` on `main`, served by GitHub Pages.
- Progress is saved automatically to `data.json` on the `data` branch, about 2 seconds after each change.
- To connect a device: open the page, press **Sync off** at the top right, paste a fine-grained token with *Contents: read and write* on this repo, and press **Connect**. The token stays in that browser.
